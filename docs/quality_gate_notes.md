# 影像防呆測試紀錄（2026/08/10）

App 判讀前會先檢查照片品質。太暗、太亮、太模糊，或看起來不像耳鏡拍的照片，會先擋下並提示使用者。這份紀錄整理目前的門檻和測試結果。

## 目前的門檻（初版）

原始碼在 `ImageQualityChecker.kt`。

| 檢查 | 擋下的條件 | 說明 |
|---|---|---|
| 太暗 | 平均亮度 < 60 | 亮度以灰階 0～255 表示 |
| 太亮 | 平均亮度 > 200 | 同上 |
| 太模糊 | Laplacian 變異數 < 45 | 照片先縮到 200 px 再算，數值越小代表邊緣越不清楚 |
| 不像耳鏡照片 | 四角平均亮度 ≥ 40，或中心減四角的亮度差 ≤ 50 | 四角各取邊長 15%、中心取邊長 35% 的區塊比較。耳鏡照片通常四周黑、中間亮 |

目前數值是用以下的測試照片試出來的（9 張真實照片、12 張測試圖）。如之後有更多實際使用的照片，要重新看數值分布再調整，不能當成固定標準。

## 測試照片

- 真實耳膜照片 9 張：從院內影像挑選，包含 Normal（正常）、AcuteMyringitis（急性鼓膜炎）、AcuteOtitisMedia（急性中耳炎）、CerumenImpaction（耳垢栓塞）、TympanicMembranePerforation（鼓膜穿孔）。
- 用程式產生的測試圖 12 張：純黑、純白、偏黑的雜訊、偏白的雜訊、隨機雜訊、漸層天空、幾何圖形組成的場景、模糊處理過的真實照片（正常、異常各一張）、調暗的真實照片，以及 2 張故意用來騙過形狀檢查的圖（黑邊加灰白圓盤、暗畫面加右上角亮點）。

## 測試結果

- 9 張真實照片全部通過，沒有誤擋。
- 12 張測試圖擋下 11 張，漏掉 1 張。

| 測試圖 | 結果 | 原因 |
|---|---|---|
| pure_black、pure_white | 擋下 | 太暗、太亮 |
| near_black_noise、near_white_noise | 擋下 | 太暗且太模糊、太亮且太模糊 |
| random_noise | 擋下 | 不像耳鏡照片（四角和中間一樣亮） |
| gradient_sky | 擋下 | 太模糊、不像耳鏡照片 |
| scene_landscape | 擋下 | 不像耳鏡照片（四角太亮） |
| blurred_real_normal、blurred_real_abnormal | 擋下 | 太模糊 |
| dark_real_normal | 擋下 | 太暗且太模糊 |
| vignette_fooler_moon | 擋下 | 太暗（整張偏暗，不是靠形狀檢查擋下的） |
| vignette_fooler_disc | 沒擋下 | 黑邊加灰白圓盤騙過形狀檢查，模型判成 Abnormal（異常），信心值 73.4% |

## 目前的限制

1. 形狀檢查只看「四角暗、中間亮」，不知道照片內容是什麼，所以黑邊加上中間亮的圓形就能通過。需要另外訓練一個判斷「是不是耳鏡照片」的模型，或加上其他更嚴格的圓形偵測。
2. 信心值不能拿來把關。漏掉的那張信心值是 73.4%，比真實照片的 98～100% 低，但另外測的棋盤格圖，信心值從 70% 到 99% 都有，不夠穩定，所以目前沒有把「信心值偏低」當成擋下的條件。


## 轉換後的一致性

- 同一個 `best_float16.tflite`，在電腦上（Python的ai_edge_litert）和App上跑同樣 9 張真實照片，判讀結果和信心值都一致。
- ONNX（float32）和 TFLite（float16）對真實照片的輸出也一致。float16的數值精度較低、檔案較小，但沒有明顯影響結果。
