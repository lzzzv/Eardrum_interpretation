# Eardrum Interpretation — 耳膜影像判讀 App

這是我在臺北榮民總醫院實習期間開發的 Android App，可以選一張耳鏡拍的耳膜照片，由手機上的 AI 模型判斷耳膜看起來是正常還是異常。目前還在開發中，功能不算完整。

## 主要功能

- **選擇照片**：從手機相簿選一張耳膜照片
- **照片品質檢查**：先檢查照片會不會太暗、太亮、太模糊，或根本不是耳鏡照片，不合格就請使用者重選
- **AI 判讀**：用訓練好的影像分類模型判斷「正常」或「異常」，並顯示信心程度（高 / 中 / 低）
- **離線執行**：模型直接在手機上運算，照片不會上傳

品質檢查的測試過程記錄在 [`docs/quality_gate_notes.md`](docs/quality_gate_notes.md)。

## 使用技術

Kotlin、TensorFlow Lite、YOLO 影像分類模型

## 執行方式

用 Android Studio 開啟專案，在手機或模擬器上執行，點「從相簿選擇圖片」即可。
